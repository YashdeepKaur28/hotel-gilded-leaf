# Hotel Gilded Leaf — Luxury Hotel Website 🏨

A responsive, multi-page **luxury hotel website** built entirely with **pure HTML5 and CSS3** — no frameworks, no JavaScript, no build tools. Features a premium dining menu, room listings, booking form, guest reviews, and full authentication UI.

## 📖 Overview

**Hotel Gilded Leaf** is a fictional 5-star resort website that showcases hospitality, luxury suites, and a dynamic culinary menu. The project demonstrates **semantic HTML5 structure, CSS Grid, Flexbox, responsive design, and a consistent design system** across 9 pages.

Built to practice:
- **Multi-page site architecture** with shared nav + footer
- **CSS Grid & Flexbox** for card layouts and responsive sections
- **Mobile-first responsive design** with media queries
- **Form design** (login, register, booking, contact)
- **Reusable CSS design system** — colors, spacing, typography
- **SEO-friendly semantic HTML** (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)



## ✨ Features

- 🏠 **Home page** with hero banner and welcome section
- 🍽️ **Culinary Menu** — 9 gourmet dishes in a responsive grid
- 🛏️ **Rooms** — 3 luxury suite cards with pricing and booking CTA
- 📅 **Booking form** — room selection, dates, guests, special requests
- ⭐ **Reviews page** — guest testimonials in card layout
- 📞 **Contact page** — full contact form with validation
- 🔐 **Login & Register** — full auth UI pages
- 📖 **About page** — brand story with image gallery
- 📱 **Fully responsive** — works on mobile, tablet, desktop
- 🎨 **Consistent design system** — orange/gray/white palette
- 🖼️ **Sticky navbar** with active-state highlighting
- 🦶 **Footer with quick links** on every page

## 🎨 Design System

| Element | Value |
|---------|-------|
| Primary accent | `#e67e22` (orange) |
| Dark base | `#2c3e50` (navy) |
| Light background | `#fbfbfc` |
| Text | `#2c3e50` |
| Border | `#e1e8ed` |
| Font family | `Segoe UI, Tahoma, Verdana` |

**Layout system:**
- `.content-grid` — 3-column responsive grid (3 → 2 → 1 on smaller screens)
- `.form-container-box` — centered max-width 450px form wrapper
- `.header-strip` — sticky top nav
- `.footer-strip` — dark footer with auto-bottom push

---

## 📱 Responsive Breakpoints

| Breakpoint | Effect |
|-----------|--------|
| ≤ 900px | Grid drops to 2 columns |
| ≤ 768px | Navbar stacks vertically, links wrap |
| ≤ 600px | Grid drops to 1 column |
